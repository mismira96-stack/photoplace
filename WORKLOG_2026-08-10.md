## Product Decision

V2 direction was clarified as:

```text
Display First, Organize Optional
```

PhotoPlace should first show location-based memories inside the app. Gallery album creation remains a core feature, but it should become an explicit next action after the user sees what was found.

This is driven by real user feedback:

- Some users fear automatic album/file changes.
- Some users want location-based browsing more than folder creation.
- Users search for countries/places directly, such as `일본`, before thinking about album organization.
- Repeated-place recommendations are part of the core memory direction:
  - broad groups like `수원 400장` or `성남 800장` should be able to reveal smaller user-meaningful places.
  - likely examples include home, company, family home, or ballet academy.
  - this should be user-confirmed Personal Place, not automatic POI promotion.
- Add a Candidate Quality Validation gate before building Personal Place UI:
  - generate top candidates from real photo data.
  - manually inspect photos/date distribution/coordinate spread.
  - label each candidate meaningful / ambiguous / false positive.
  - tune radius/count/date thresholds before treating them as product specs.
- No-location folder movement should move down in priority. Once discovery snapshots remember analyzed files, unchanged no-location items can be skipped without moving them into a separate folder.

## Architecture Boundary

Gemini's concern about tight Gallery coupling is valid.

Current V1/V1.2 structures assume real Gallery albums:

- `AlbumSummaryHistoryStore` stores created album history.
- `StoredAlbumSummary` depends heavily on `relativePath`.
- detail/gallery actions load photos via MediaStore album folder paths.
- `filterLiveStoredAlbumSummaries()` removes records if the live Gallery album is missing.
- `MemoryPersonalizationKey` currently prefers `path:{relativePath}`.

Therefore V2 Display First must not be implemented by forcing discovery-only records into `AlbumSummaryHistoryStore`.

Required separation:

```text
AlbumSummaryHistoryStore
  = organized Gallery album history

DiscoverySnapshotStore
  = analysis result before/without album creation

MemoryRepository
  = adapter that merges organized albums and discovery-only snapshots for UI
```
