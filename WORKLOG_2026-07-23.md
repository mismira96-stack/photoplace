### Existing User Migration

Existing users may already have `Pictures/*에서/` albums but no country metadata.

Migration paths:

- Manual: Settings -> `발견 장소 다시 만들기`
- Automatic: one-time background backfill after update when permissions are already granted

Backfill scans existing generated albums and attempts to recover country metadata from EXIF/video GPS. If metadata cannot be recovered, `OverseasMemoryGrouper` has conservative fallback mapping for known overseas place names.

Known fallback examples:

- Japan: `Fukuoka`, `Kurume`, `Tosu`, `Yufu`, `Tsushima`
- Australia: `Melbourne`, `Sydney`, `Wollongong`, `PortCampbell`, etc.
- Guam: `투몬`, `Tumon`

Korean romanized exceptions such as `Mapo-gu` and `Songpa-gu` are excluded from overseas grouping.

### No Location Cache

Added `NoLocationCache.java`.

Purpose:

- Avoid repeatedly reading EXIF/video metadata for files already known to have no location.
- Improve repeat scan performance for users with many no-location photos.

Signature:

```text
uri + filename + date_modified + date_added + datetaken + media type
```

If any of these changes, the item is rechecked.
