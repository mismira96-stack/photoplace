# Worklog - 2026-08-30

## Date-Based Memory Note MVP

- Added `MemoryIdentityRegistryStore`: a persistent alias-to-stable-id registry for user-authored Memory data.
  - A discovery alias such as `discovery:<placeKey>` receives an immutable `mem_...` id only when the user saves a note.
  - Existing aliases cannot be reassigned to another id.
- Added `MemoryDateNote` and `MemoryDateNoteStore`.
  - Notes use `memory-id:<stable-id>#yyyyMMdd` keys.
  - The store uses tmp/bak atomic writes, backup restoration, and refuses to overwrite an unrecoverable corrupt file.
- Added date-section note UI to the discovery Memory detail.
  - Each valid date header exposes `메모` or `수정`.
  - Notes are one line, up to 80 characters, with save, edit, and delete.
  - The date editor now reuses the existing PhotoPlace memory-editor card instead of a platform default dialog.
