## Code Added

Added:

- `MemoryRepository`
- `MemoryRepositoryTest`

Behavior:

- Converts `DiscoveryMemoryGroup` into `MemoryRecord` with `MemorySourceType.DISCOVERED_ONLY`.
- Converts `StoredAlbumSummary` into `MemoryRecord` with `MemorySourceType.ORGANIZED_ALBUM`.
- Keeps discovery-only records out of `AlbumSummaryHistoryStore`.
- Keeps discovery-only detail based on `DiscoveryPhotoRef.sourceUri`.
- Provides read-only lookup:
  - `memories()`
  - `memory(memoryKey)`
  - `discoveryPhotoRefs(memoryKey)`
- Merges records only when the exact `memoryKey` already matches.
- Does not guess that an organized album and discovery group are the same memory based on title, country, city, or folder name.

Important boundary:

- No UI wiring yet.
- No `MainActivity` change.
- No Gallery album creation.
- No writes to organized album history.
- No Personal Place candidate generation.

## Gemini Review Prompt

한글로 답변해줘.

리뷰 대상:

- `app/src/main/java/com/example/gallerysorter/MemoryRepository.java`
- `app/src/test/java/com/example/gallerysorter/MemoryRepositoryTest.java`

검토 목적:

- PhotoPlace V2 Memory browsing first 기반에서 discovery-only memory와 organized album memory를 읽기 전용으로 합치는 첫 Repository 패치가 안전한지 확인.

검토 포인트:

1. `MemoryRepository`가 읽기 전용 facade 역할만 하고 있는지.
2. `DiscoveryMemoryGroup -> MemoryRecord` 변환에서 `DISCOVERED_ONLY` source type, source refs, country/admin/address/date/count/cover metadata가 보존되는지.
3. `StoredAlbumSummary -> MemoryRecord` 변환에서 실제 Gallery album과 discovery-only memory가 섞이지 않는지.
4. discovery-only record를 `AlbumSummaryHistoryStore`에 쓰지 않는 경계가 잘 지켜졌는지.
5. 같은 `memoryKey`일 때만 `MIXED`로 병합하는 보수적 정책이 MVP 단계에 적절한지.
6. organized album과 discovery group을 title/country/city로 추측 병합하지 않는 결정이 안전한지.
7. `canOpenPhotos`, `canOpenGalleryAlbum`, `canOrganize`, `canAddNewItems` flag 의미가 다음 UI 단계에 적절한지.
8. 다음 단계에서 UI wiring 전에 추가해야 할 테스트나 데이터 계약이 있는지.

특히 확인할 점:

- 이 패치가 `MainActivity`로 책임을 다시 밀어넣지 않는 구조인지.
- Memory browsing first 원칙인 "Display First, Organize Optional"을 해치지 않는지.
- 다음 패치에서 `MainActivity`를 얇은 wiring만 하도록 유지하려면 어떤 adapter/controller가 더 필요한지.

블로커와 논블로커를 나눠서 리뷰해줘.
