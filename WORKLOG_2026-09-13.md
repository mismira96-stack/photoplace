## OrganizationLink Worker Lifecycle Review Fixes

- Gemini review identified a result-processing loop if an invalid OrganizationLink payload or permanent store conflict returned the same failure every two seconds.
- Split organization-result persistence outcomes into not-required, persisted, retryable failure, and permanent failure.
- Invalid link payloads and `CONFLICT` / `INVALID` commit results now stop retrying and continue to the normal sort-result screen without claiming an organized Memory link.
- Transient persistence failures retry up to three attempts. After the limit, the app exits the progress loop and displays the normal result with a warning that the Memory connection was not saved.
- Album history is saved before link validation/commit. Successful history persistence is not redundantly repeated when the result screen is shown; retry exhaustion still gives the ordinary result handler a final history-save attempt.
- `OrganizationLink.organizedAtMillis` now uses the persisted Worker completion timestamp, with current time only as a fallback for older/invalid snapshots.
- Documented that a `path:` alias already owned by another Memory is never overwritten; the request's exact OrganizationLink remains authoritative.

## Exact MemoryRepository Link Resolution

- Added a read-only alias snapshot API to `MemoryIdentityRegistryStore` and passed identity aliases plus organization links into `MemoryRepository` through `DiscoverySnapshotController`.
- `MemoryRepository.memories()` now resolves a discovered Memory's stable ID, selects its latest usable `MEMORY` link, and merges only with the `StoredAlbumSummary` at that exact normalized output path.
- When an exact link exists but its output album is absent from current Gallery summaries, legacy same-name/date heuristics are suppressed for that Memory. This avoids attaching it to an unrelated album.
- Kept the existing constructor and legacy matching behavior for callers/data without exact link context.
- Added tests for exact-link precedence across differing display names and for missing linked output refusing heuristic merge.
