## Code Added

Added:

- `DiscoverySnapshotStore`
- `DiscoverySnapshotStoreTest`

Store behavior:

- Reads missing snapshot as an empty `DiscoverySnapshot`.
- Saves and restores the current `DiscoverySnapshotJson` schema.
- Writes through a temp file and keeps a backup during replacement.
- Restores `.bak` if the main snapshot file is corrupt.
- Refuses to overwrite a corrupt snapshot if no valid backup exists.
- Clears target/temp/backup snapshot files.
